# 策略执行系统重构计划 — 从框架到容器+工具箱

## 目标

将 `strategy_execution` 从「规定策略怎么跑的框架」重构为「提供能力的容器+工具箱」，使得：

1. **任何市场**（天气/体育/电竞/政治）的策略都能接入
2. **任何逻辑**（扫单/跟单/做市/套利/事件驱动）的策略都能实现
3. **每个策略和信号源**都是独立微服务，互不影响
4. 新增策略不需要改动 runtime 或基础设施代码

## 现有问题

| 问题 | 具体表现 |
|------|---------|
| BaseStrategy 绑定特定事件类型 | `on_leader_signal`, `on_tick_candidate` — SweepStrategy 被迫实现空方法 |
| 状态机固定 | 6 个状态 + 固定转换表，做市策略不适用 |
| 风控强制注入 | 所有策略必须用 `RiskManager`(止损逻辑)，但套利策略的风控是对冲敞口 |
| 信号源硬编码 | runtime 里写死 `NEEDS_WEATHER` / `NEEDS_LEADER` |
| 资金管理强制 | 必须用 `AccountExecutionLedger`，但有些策略可能跨账户操作 |
| `copy_trading/` 与 `strategy_leader/` 功能重叠 | 两套跟单逻辑并存 |
| `market/` 定位模糊 | 既是数据查询又是退出监控，被多个不相关模块直接依赖 |

## 核心接口定义 (`strategy_runtime/interfaces.py`)

```python
from __future__ import annotations
from abc import ABC, abstractmethod
from dataclasses import dataclass, field
from typing import Any, ClassVar, Protocol

# ─── 通用信号 ─────────────────────────────────────────────────

@dataclass(frozen=True)
class Signal:
    """所有信号源必须输出此格式。"""
    signal_id: str              # 全局唯一 ID
    signal_type: str            # "sweep", "leader_buy", "news", "arb_opportunity"
    token_id: str               # Polymarket token
    market_slug: str            # 所属市场
    occurred_at_ms: int         # 信号产生时间
    source: str                 # 信号源标识: "weather_orderbook", "sports_monitor"
    payload: dict = field(default_factory=dict)  # 信号源特有数据


# ─── 策略协议 ─────────────────────────────────────────────────

class BaseStrategy(ABC):
    """策略最小约束 — 只规定生命周期，不规定内部实现。"""

    # 策略声明订阅哪些信号类型（container 据此决定连接哪些信号源）
    SUBSCRIBED_SIGNALS: ClassVar[set[str]] = set()

    @abstractmethod
    async def start(self, ctx: "StrategyContext") -> None:
        """初始化：策略从 ctx 获取需要的工具，设置内部状态。"""

    @abstractmethod
    async def on_signal(self, signal: Signal) -> None:
        """收到信号 — 策略自行决定如何处理。"""

    @abstractmethod
    async def stop(self) -> None:
        """关闭：取消定时器、撤销挂单、释放资源。"""


# ─── 策略上下文 ────────────────────────────────────────────────

@dataclass
class StrategyContext:
    """工具箱入口 — 策略按需使用，不强制全部依赖。"""
    executor: "OrderExecutorProtocol"      # 下单/撤单
    state_store: "StateStoreProtocol"      # 自定义状态持久化
    config: dict[str, Any]                 # 策略配置参数
    proxy_wallet: str                      # 执行钱包
    run_id: str                            # 本次运行 ID


# ─── 能力协议（工具箱内各组件的接口） ──────────────────────────

class OrderExecutorProtocol(Protocol):
    async def place_order(self, token_id: str, side: str, price: str,
                          size: str, **kwargs) -> "OrderResult": ...
    async def cancel_order(self, order_id: str) -> bool: ...

class StateStoreProtocol(Protocol):
    async def save(self, run_id: str, state: dict) -> None: ...
    async def load(self, run_id: str) -> dict | None: ...

@dataclass(frozen=True)
class OrderResult:
    order_id: str
    status: str                # "filled", "partial", "live", "failed"
    filled_size: str
    filled_price: str | None
```

## 容器 (`strategy_runtime/container.py`)

Container 使用 `toolkit/signals/ws_client.py` 连接信号源：

```python
from toolkit.signals.ws_client import SignalWSClient

class StrategyContainer:
    """极简容器 — 生命周期 + 信号接收。"""

    def __init__(
        self,
        strategy_class: type[BaseStrategy],
        config: dict,
        signal_sources: list[SignalSourceConfig],
    ):
        self._strategy = strategy_class()
        self._config = config
        self._signal_sources = signal_sources
        self._ws_tasks: list[asyncio.Task] = []

    async def start(self) -> None:
        ctx = self._build_context()
        await self._strategy.start(ctx)
        for source in self._signal_sources:
            client = SignalWSClient(url=source.url, adapter=source.adapter)
            self._ws_tasks.append(
                asyncio.create_task(client.listen(self._strategy.on_signal))
            )

    async def stop(self) -> None:
        for task in self._ws_tasks:
            task.cancel()
        await self._strategy.stop()

    def health(self) -> dict:
        return {"status": "ok", "ws_connections": len(self._ws_tasks)}
```

## 现有策略改写示例

### SweepStrategy（改写后）

```python
from strategy_runtime.interfaces import BaseStrategy, Signal, StrategyContext
from toolkit.risk.stop_loss import StopLossMonitor
from toolkit.market.tick_verifier import TickVerifier

class SweepStrategy(BaseStrategy):
    SUBSCRIBED_SIGNALS = {"sweep"}

    async def start(self, ctx: StrategyContext) -> None:
        self.ctx = ctx
        self.state = "idle"
        self.position_shares = Decimal("0")
        self.entry_order_id = None

        # 按需创建工具（可替换为自己的实现）
        self.risk = StopLossMonitor(
            ratio=Decimal(ctx.config.get("stop_loss_ratio", "0.6")),
            on_trigger=self._risk_exit,
        )
        self.tick_verifier = TickVerifier()

    async def on_signal(self, signal: Signal) -> None:
        if signal.signal_type == "sweep" and self.state == "idle":
            await self._enter(signal)
        elif signal.signal_type == "bbo_update":
            await self.risk.check(signal.payload)
        elif signal.signal_type == "tick_change":
            await self._check_tick_exit(signal)

    async def stop(self) -> None:
        if self.entry_order_id:
            await self.ctx.executor.cancel_order(self.entry_order_id)

    async def _enter(self, signal: Signal) -> None:
        fixed_shares = self.ctx.config.get("fixed_entry_shares", "100")
        result = await self.ctx.executor.place_order(
            token_id=signal.token_id,
            side="BUY",
            price="0.99",
            size=fixed_shares,
        )
        if result.status == "filled":
            self.state = "holding"
            self.position_shares = Decimal(result.filled_size)
            self.risk.start(entry_price=Decimal(result.filled_price))

    async def _risk_exit(self) -> None:
        await self.ctx.executor.place_order(
            token_id=..., side="SELL", price="0.01", size=str(self.position_shares))
        self.state = "closed"

    async def _check_tick_exit(self, signal: Signal) -> None:
        if await self.tick_verifier.verify(signal.payload["token_id"]):
            await self.ctx.executor.place_order(
                token_id=..., side="SELL", price="0.999", size=str(self.position_shares))
            self.state = "closed"
```

## 关键设计决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 策略状态持久化 | 策略自定义 state dict，container 帮忙存 | 不同策略状态结构完全不同 |
| 风控 | 工具箱可选组件，策略自己决定用不用 | 做市策略和趋势策略风控逻辑完全不同 |
| 信号过滤 | 策略 on_signal 内部自己过滤 | runtime 不该知道业务过滤规则 |
| 订单管理 | 工具箱提供 executor，策略自己管理订单生命周期 | 有些策略同时挂多单，有些只有一单 |
| 多运行防重 | 策略自己实现（或用工具箱的 guard 组件） | 不是所有策略都需要防重 |
| market/ 归属 | 迁移到 toolkit/market/，不保留独立目录 | 它是工具组件不是独立服务 |
| copy_trading/ | 直接删除 | 功能完全被新架构覆盖 |
| 工具箱组件可继承 | class 设计，子类可 override 任何方法 | 策略可以复用 80% 逻辑，只改关键部分 |
